## 根因

1. 默认启动源错误：第 1 条“多多内置”当前无法取得首页数据。
2. 清单质量不足：23/40 在配置下载或格式识别阶段失败，不应作为默认可用源展示。
3. JS 兼容链不完整：相对 JS URL 未基于配置 URL 解析，且部分 drpy 脚本无法在现有 QuickJS 环境执行。
4. JAR/CSP 尚不支持：部分配置虽然能解析，但所有站点都依赖 Java 爬虫。
5. 直播源与点播源混放：第 40 条只有直播内容，不能用于首页点播启动。
